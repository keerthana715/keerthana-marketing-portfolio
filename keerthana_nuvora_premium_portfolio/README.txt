KEERTHANA — PREMIUM MARKETING PORTFOLIO
======================================

This is a responsive static website built with HTML, CSS, and JavaScript. It presents beginner-level AI video/content experiments honestly and labels hospitality marketing ideas as practice concepts, not professional experience.

FILES
-----
index.html  = page content and portfolio sections
style.css   = visual design and mobile-responsive layout
script.js   = mobile navigation, contact links, and copy sample outreach message

IMPORTANT BEFORE PUBLISHING
---------------------------
1. Open script.js in Notepad or Visual Studio Code.
2. Replace your.email@example.com with your real email address.
3. Add your LinkedIn URL and Instagram URL between the quotes.
4. Review all wording and remove anything that does not accurately describe you.
5. The hospitality campaign, partnership proposal, and event plan are practice concepts only—not work delivered for Nuvora Stays or any client.
6. The measurement section explains what you could track; it does not claim any campaign results. Decorative bars are not real data.
7. Do not publish private phone numbers or other information you do not want public.

OPEN ON YOUR LAPTOP
-------------------
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html to preview it in your browser.
4. Keep all three website files in the same folder.

PUBLISH FREE WITH GITHUB PAGES
------------------------------
1. Go to https://github.com/ and sign in.
2. Create a new repository named keerthana-marketing-portfolio.
3. Set the repository to Public, then create it.
4. Open the repository and choose Add file > Upload files.
5. Upload index.html, style.css, and script.js from the extracted folder (not the ZIP file).
6. Commit the uploaded files.
7. Go to Settings > Pages.
8. Under Build and deployment, select "Deploy from a branch".
9. Choose branch "main" and folder "/ (root)", then click Save.
10. Wait a few minutes and refresh the Pages settings to find the published URL.
11. It should look similar to:
    https://YOUR-GITHUB-USERNAME.github.io/keerthana-marketing-portfolio/
    Replace YOUR-GITHUB-USERNAME with your actual GitHub username.
12. Open the URL and check the site on both laptop and phone.

NOTES
-----
- The site uses Google Fonts, so the chosen fonts need an internet connection. System fallback fonts will still display if fonts cannot load.
- GitHub Pages publishes files publicly. Only publish details you are comfortable sharing.
- If you rename the repository, the final URL changes too.
